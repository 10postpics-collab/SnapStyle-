## 🌟 What is SnapStyle?

SnapStyle is a full-featured social media web app built with pure HTML, CSS, and JavaScript — no frameworks, no backend, no dependencies. Just one file that runs anywhere.

Built for creators, sharers, and anyone who wants to connect with their world in real time.

---

## ✨ Features

| Feature | Description |
|---|---|
| 👻 **Stories** | Animated story rings with timed snap viewer |
| 📸 **Camera** | Filter system with 7 visual styles |
| 🎬 **Reels** | Swipe-up short video feed |
| 💬 **DM Chat** | Full messaging with live auto-reply |
| 🔍 **Discover** | Trending content grid with category filters |
| 🔥 **Streak System** | Daily snap streak tracker |
| ⭐ **SnapScore** | Creator score on every profile |
| ✓ **Verified Badges** | Blue checkmarks for top creators |
| 📍 **Location Tags** | Geo-tags on snaps |
| ❤️ **Reactions** | Like with heart burst animation |
| 💬 **Comments** | Inline commenting on every post |
| 👤 **Profiles** | Full user profiles with snap grids |

## 🛠 Getting Started

### Run Locally
1. Download `index.html`
2. Open it in any browser
3. That's it — no install needed ✅

### Deploy to GitHub Pages
1. Fork or upload this repo
2. Go to **Settings** → **Pages**
3. Set source to **main branch / root**
4. Your site goes live at `https://YOUR-USERNAME.github.io/snapstyle`
